# Frontends

- **03 a 05:** independentes de backend.
- **06 a 13:** execute `backend/Exercicio02-apirestful` no outro terminal.
- **15 e 16:** execute `backend/Exercicio14-apirestfulv2` no outro terminal.

A primeira API passa a ser usada no exercício 06; a mudança de versão ocorre no exercício 15. Os números originais foram mantidos para acompanhar o material da disciplina.

Entre na pasta da atividade e execute `npm install` e `npm run dev`. No 06, entre em uma das subpastas `await-try-catch` ou `fetch-then-then-catch`. O Vite informa a URL para abrir no navegador e encaminha `/api` ao backend em `http://localhost:8080`.

Os caminhos completos e os comandos dos dois terminais estão no [README principal](../README.md).
